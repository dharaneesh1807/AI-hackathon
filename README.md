# Catalyst ElderCare — AI-Powered Connected Care OS

A full-stack, accessible elderly-care platform featuring
AI prescription transcription, closed-loop medication
adherence, caregiver collaboration, automated reminders,
secure healthcare sharing, and wellness monitoring.

## Live Application

https://catalyst-eldercare.onrender.com

## Current Implementation

- CareLens: Google Gemini prescription transcription
- CarePulse: Closed-loop medication adherence
- CareCircle: Role-based caregiver collaboration
- CareSOS: Emergency contact assistance
- CarePassport: Expiring QR-based care sharing
- CareCheck: Wellness monitoring
- RefillGuard: Medication inventory tracking
- CareVoice: Consent-based telephone escalation
- Progressive Web App and multilingual comfort mode

## Quality and Safety

- 24 automated tests passing
- Argon2 password hashing and JWT authentication
- Profile-level authorization and role-based access
- Idempotent reminder dispatch
- PostgreSQL persistence
- Privacy-minimal notifications
- Human verification of AI-extracted prescriptions
